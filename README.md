# Jay Krishna Mishra Portfolio

A modern, responsive React portfolio website for a Data Analyst / aspiring Data Scientist.

## Setup

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Customize

- Replace `public/resume.pdf` with your real resume.
- Update links and text in `src/data/portfolioData.js`.
- Replace the profile image in `src/components/Hero.jsx` if you want to use your own image.

## Deploy To GitHub Pages

```bash
npm run build
```

Then deploy the generated `dist` folder using your preferred GitHub Pages workflow.
